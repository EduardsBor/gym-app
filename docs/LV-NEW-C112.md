# Новые LV-строки: C-112 (программы-блоки)

Нужна проверка носителем. В LV-REVIEW.md и в файл Эдуарда не добавлялись. Формат: RU → EN → LV. Все строки в `i18n/dict3.js`.

| RU | EN | LV |
|---|---|---|
| Повторить блок | Repeat the block | Atkārtot bloku |
| Следующий уровень | Next level | Nākamais līmenis |
| Блок завершён | Block complete | Bloks pabeigts |
| Пропустить тренировку | Skip workout | Izlaist treniņu |
| Выбери, что дальше. | Choose what to do next. | Izvēlies, kas tālāk. |
| Тренировка перенесена | Workout postponed | Treniņš pārcelts |
| Тренировка | Workout | Treniņš |

Вопросы Claude:
- «Atkārtot bloku» — кнопка на экране после последней тренировки блока.
- «Nākamais līmenis» — вторая кнопка, только если в блоке задан `next_level`.
- «Treniņš» используется в названиях «Treniņš 1» … «Treniņš N» (как RU «Тренировка 1»).
