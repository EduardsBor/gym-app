# LV-NEW-WORKOUT-NUMBERS — нумерация тренировок 1…N без буквы A/B/C

Нужна проверка носителем. В LV-REVIEW.md и в файл Эдуарда не добавлялись. В `i18n/dict*.js` новые строки не вносились.

На экране (план, текущая тренировка, история) название дня больше не содержит суффикс A/B/C. Формат: `12. Всё тело`, при разгрузке `16. Всё тело (разгрузка)`. В хранилище по-прежнему `Неделя N · Всё тело A` — буква снимается только при показе.

Уже есть в словаре (используются после снятия буквы):

| RU | EN | LV (уже в dict) |
|---|---|---|
| Всё тело | Full body | Viss ķermenis |
| Верх тела | Upper body | Ķermeņa augšdaļa |
| Низ тела | Lower body | Ķermeņa apakšdaļa |
| Жимовая | Push | Spiešana |
| Тяговая | Pull | Vilkšana |
| Ноги | Legs | Kājas |
| Фулбоди | Full body | Viss ķermenis |
| разгрузка | deload | atslodze |
| Неделя | Week | Nedēļa |
| Тренировка | Workout | Treniņš |

Могут появиться у старых/шаблонных программ после снятия буквы с «Верх A» / «Низ A». Предложение, в словарь не добавлялось:

| RU | EN | LV (предложение) |
|---|---|---|
| Верх | Upper | Augšdaļa |
| Низ | Lower | Apakšdaļa |
