# D-287 — снятые LV-строки (без новых)

Эдуард: убрать «Kā gāja? (nav obligāti)» совсем, на всех языках.

С карточки упражнения во время тренировки удалены:

- `Kā gāja?` (RU «Как прошло?», EN «How did it go?»)
- `(nav obligāti)` как отдельная подпись к этой строке (RU «(необязательно)», EN «(optional)»)

Кнопки «viegli / normāli / grūti» больше не показываются. Словарные строки `viegli` / `normāli` / `grūti` оставлены: они нужны для экспорта старых записей, где `feel` уже сохранён. Сами сохранённые значения в данных пользователя не удалялись.
