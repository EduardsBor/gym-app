# Changelog

## [Unreleased]

- D-214: отдельные упражнения для каждого места. Для дома и своего веса — свои id с правильными метками: «Подъём на носки на одной ноге с гантелью» (`calf-db`), «… без веса» (`calf-bw`), «Зашагивания на ступеньку без веса» (`step-bw`), «Французский жим лёжа с гантелями» (`skull-db`), «Быстрая ходьба (улица или на месте)» (`walk-brisk`, без ролика по решению Эдуарда). У зала прежние id. Метки исправлены: подъём на носки в тренажёре, ходьба на дорожке, EZ-гриф — только зал; зашагивания с гантелями — зал и дом; тяга резинки к лицу — зал и дом. Роликов у новых id пока нет (список согласуют тренер и Claude).
- Сохранённый план пользователя «дом» / «свой вес» один раз переводится на новые id (`S.placeIds`). История тренировок и начатая тренировка не меняются.
- В библиотеке у каждого упражнения значки мест (🏢 🏠 🤸).
- Кэш service worker: moyzal-v44 (+ place.js).

- Для упражнений с роликом MoveKit удалены старые файлы anim3d (mp4 и jpg). Если ролик не загрузился и копии в кэше нет, показывается «Анимация в разработке». Старые ролики оставлены только у упражнений без MoveKit.
- Кэш service worker: moyzal-v40. Клипы: moyzal-anim3d-v13 (старый кэш роликов сбрасывается). Кэш MoveKit не удаляется при обновлении.

- Видео MoveKit для упражнений из карты (подписанная ссылка только в памяти, файл в Cache Storage `moyzal-movekit-v1`). Если ролика нет, или он не загрузился и копии нет — прежняя 3D-анимация. Файлы anim3d не удалялись.
- Кэш service worker: moyzal-v39. Клипы: moyzal-anim3d-v12. Кэш MoveKit не удаляется при обновлении.

- Калории без датчика: оценка по весу, длительности и MET (разминка и заминка — низкая интенсивность, силовые — умеренно или интенсивно по типу упражнения, кардио — по типу). Если веса нет, приложение спрашивает один раз. Подпись: «≈ ккал, оценка».
- Пульсометр по Web Bluetooth (Heart Rate 0x180D / 0x2A37), если `navigator.bluetooth` есть. Иначе короткая пометка, что пульсометр будет в версии из магазина. При сигнале пульса калории считаются по Keytel et al. 2005 и возвращаются к MET, где сигнала нет. В историю добавлены только необязательные поля: ккал, средний и максимальный пульс, время в 5 зонах.
- Кэш service worker: moyzal-v38. Клипы: moyzal-anim3d-v12.
- Заменены ролики fsq, cru, jump и wlk (id упражнений те же).
- Заменён ролик lr (id упражнения тот же).
- Заменён ролик w_march (id упражнения тот же).

- Библиотека: 93 новые карточки из справочника v2 (тексты раздела B — по решению тренера). Видео нет: в технике пометка «Анимация в разработке». 60 упражнений добавлены в пулы автопрограмм (уровень и инвентарь); 33 только в библиотеке, в рабочие подходы и в блок разминки не ставятся. У `mch` текст снова про горизонтальный жим (рукоятки на высоте середины груди); id и файл видео не менялись — ролик пока наклонный. `mch-incline` — отдельная карточка.
- Техника 17 упражнений (RU/EN/LV): шаги, ошибки и безопасность приведены к решению тренера и эталону v2. У `ur` обновлено отображаемое название, id не менялся. У `ht` теги инвентаря `gdb` сохранены, потому что от них зависит подбор домашних программ; текст карточки описывает штангу, гантель и вариант без веса.
