- P-301 (принято Claude): авто-вес по правилам тренера (`progression-rules.json`). Логика — в отдельном модуле `progress.js` (без DOM), подключение к приложению — `autow.js`.
  - Двойная прогрессия: все рабочие подходы на верхней границе диапазона (и запас RIR не ниже нормы) → прибавка; новичок и средний — после 1 такой тренировки, опытный и любой флаг риска — после 2. После прибавки цель — нижняя граница.
  - Шаг по снаряду: штанга верх +2,5, низ +5 (до 40 кг +2,5); гантели верх +1, низ +2 с округлением до ближайшей гантели; тренажёр/блок — 1 шаг; гиря и резинка — следующая. При флаге риска — минимальный шаг.
  - Промахи: 1 — вес тот же; 2 подряд — на подход меньше (не меньше 2); 3 подряд — вес −10 % (вниз до доступного), прогрессия заново. Гравитрон: противовес −5 за успех, +5 после 3 промахов, 0 → подтягивания.
  - Первая тренировка с упражнением — калибровка: вес не подставляется. Перерыв 14–27 дней — вес ×0,9; 28+ — ×0,8 и запас +1 на 2 тренировки.
  - Разгрузка: плановая каждые 6 недель (средний/опытный; новичок — с 13-й недели), отсчёт с установки этой версии; ранняя — кнопкой (новичок — всегда, остальным — если вес не растёт 3 недели в половине упражнений). Подходов вдвое меньше, запас +2, результаты не влияют на прогрессию; неделю после — промахи не считаются.
  - Свой вес: лестницы тренера (мост → на одной ноге, гравитрон/подтягивания лопатками/австралийские → подтягивания, dead bug → подъём коленей в висе → подъём ног, планка → RKC) с кнопкой «Заменить»; без лестницы — темп 3–4 с → пауза 2 с → рюкзак +5 кг, дальше +2,5. Резинки: следующий уровень, если тяжелее нет — короче резинка. Планки: цель +5 с (RKC +2 с), при флаге спины RKC нет — планка до 60 с.
  - После последнего подхода — необязательный выбор «легко / нормально / тяжело» (= RIR 3 / 1 / 0 последнего подхода).
  - Кнопка «🤕 Боль» у упражнения (бесплатно для всех): вес не повышается, оставшиеся подходы и следующая тренировка — −10 %, совет заменить упражнение.
  - «Ещё → Моё оборудование»: гантели, гири, гриф, шаг штанги/тренажёра/блока, число резинок дома (по умолчанию одна).
  - Состояние прогрессии хранится в `S.pg` по id упражнения; история тренировок не переписывается (в новую запись добавляются только `feel` и `pain`). Упражнения без класса в правилах тренера работают как раньше (последний вес).
  - Строки RU/EN/LV. Тесты: все 15 примеров тренера (`test/progress.test.js`) и сценарии приложения (`test/autow.test.js`).
- Кэш service worker: moyzal-v47 (+ progress.js, autow.js).
