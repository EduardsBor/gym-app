# movekit-sign

Выдаёт часовую ссылку на один файл из закрытого бакета `movekit`.
Только для вошедшего пользователя. Секретов в исходнике нет, ключи — из env.

## Порядок выкладки (важно)

1. Сначала выложить клиент из этого PR (sw.js `moyzal-v133` или новее, если PR #110 сольют первым — тогда кэш нужно поднять ещё на 1). Дождаться, пока живой `sw.js` сменит имя кэша.
2. Потом развернуть функцию **без** `--no-verify-jwt`:
   `supabase functions deploy movekit-sign`
3. Не наоборот: если включить `verify_jwt` до нового клиента, у текущих пользователей ролики перестанут открываться.

В `supabase/config.toml`: `[functions.movekit-sign] verify_jwt = true`.
